# Verified assessment count

Audit of the enrolled courses

**Total: 1,455 choice-based assessment question slots across 62 assessments.**

Each assessment is counted once using the question total displayed by Oracle and recorded in the live log. Single-answer, multiple-answer, and True/False choices are included. Reading, practice projects, fixture tests, retries, and repeated extraction of the current question are excluded. This is not a deduplicated inventory of Oracle's entire question bank: the early log does not retain every question's text, and quizzes can draw different questions on retries.

Evidence: the complete local bot.log, questions.jsonl, diagnostic reports and page dumps, and the final successful four-course traversal. Local logs are ignored by Git because they contain account and browser-session data.
