# Documentation

Start with the [project README](../README.md) for an overview. If you just want to run the bot, choose the setup guide below and follow it in order.

## Setup

| What you want to do | Guide |
| --- | --- |
| Use the Windows app without installing programming tools | [Desktop app guide](desktop-guide.md) |
| Download the repository and run Python | [Source setup](source-setup.md) |
| Run from source on macOS or Linux | [Source setup and platform status](source-setup.md) |

The Windows desktop ZIP includes its runtime and browser. Source setup requires Python and Google Chrome. macOS and Linux source workflows are documented but have not been validated for this project.
