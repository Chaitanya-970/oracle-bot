# 🎓 Oracle Academy Auto-Course Bot

An easy, automated helper for Oracle Academy courses. It automatically:
- Clicks **Save and Continue** on reading slides and lessons (turning them green ✅).
- Detects quizzes, reads questions, and answers them automatically using **Groq AI**.
- Handles all 4 courses on your dashboard without manual clicking.

---

## ⚡ Super Easy Setup (Under 2 Minutes)

You don't need any programming knowledge. Follow these 4 simple steps:

### 1. Get a Free Groq API Key
1. Go to [https://console.groq.com/keys](https://console.groq.com/keys).
2. Sign in with Google or GitHub (it is 100% free).
3. Click **"Create API Key"**, copy your key (it starts with `gsk_...`).

### 2. Paste Your Key
1. In this folder, open the file named **`.env`** (right-click -> *Open with* -> *Notepad*).
2. Find this line:
   ```env
   GROQ_API_KEY=your_groq_api_key_here
   ```
3. Replace `your_groq_api_key_here` with the key you copied in step 1.
4. Save the file (`Ctrl + S`) and close Notepad.

### 3. Install dependencies and start the Bot
- Install Python and Google Chrome, then run `python -m pip install -r requirements.txt` once from this folder.
- Simply double-click **`start.bat`**.

### 4. Log in
1. A Google Chrome window will pop up automatically.
2. Sign in to your Oracle Academy account inside that Chrome window.
3. Once you see your **Classes** or course page on screen, go back to the black terminal window and **press Enter**.
4. Sit back and watch! The bot will click through the lessons and solve the quizzes.

Oracle may require a fresh sign-in when Chrome restarts. The persistent profile stores browser data, but Oracle controls the lifetime of its login session.

The bot verifies the API key and model availability before opening Chrome. Current defaults are `openai/gpt-oss-120b` for text and `qwen/qwen3.8-27b` for diagrams. Both can be changed in `.env`. The older Llama defaults in the original handoff are retired for standard accounts. See [Groq's model documentation](https://console.groq.com/docs/models).

Session-extension warnings are checked between actions and during AI requests. The bot clicks the extension button in a session warning automatically. If the session already expired, it pauses for you to sign in and open Classes or the course outline before retrying.

Answers generated by AI can be wrong. Course completion is confirmed through Oracle's sidebar indicators and assessment results; the bot stops on an unrecognized state rather than claiming completion.

---

## 💡 What If It Pauses?

If the bot encounters an unusual page or needs your input:
1. It will **pause** and show a friendly message on your screen.
2. It automatically saves a picture of what went wrong in the **`logs/diagnostics`** folder.
3. Look at your Chrome browser, fix the state, open Classes or the course outline, and press **Enter** in the black window to retry. Enter `q` to stop.

---

## 📁 Folder Overview

- **`start.bat`**: Double-click this to run the bot.
- **`.env`**: Where you paste your Groq API key.
- **`logs/`**: Keeps a history of everything the bot did.
- **`logs/diagnostics/`**: If an unexpected screen happens, photos and reports are saved here.
- **`browser_profile/`**: Stores browser data; Oracle may still require another sign-in.
- **`review_live.py`**: Review harness that reloads code fixes while keeping Chrome open. `inspect` saves diagnostics, `section` tests the current section, and `run` processes the current course/dashboard.
- **`tests/`**: Offline regressions. Run `python -m unittest discover -s tests -v` (requires Chrome). Live Groq smoke checks are separate: `python -m tests.live_api_check` from this folder.

Use `run_bot.py` or `start.bat` as the supported entry point. `sections.py` and `oracle_quiz_runner_gemini_firefox_v35/` are historical experiments, not the maintained bot.
