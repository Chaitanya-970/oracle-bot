Oracle Academy Selenium Automation Prototype

This directory contains the initial Selenium-based prototype for Oracle Academy course and quiz handling.

OVERVIEW:
- Used Selenium WebDriver with Firefox.
- Normal questions were extracted directly from the Oracle DOM.
- Multimodal and diagram questions captured screenshots of the question region.
- Retained here for experimental reference and comparison.

Note: The active production runner is located in `bot/` and uses Playwright Chrome with Groq AI.
